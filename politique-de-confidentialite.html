3. Cookies et traceurs

Ce site utilise les technologies suivantes :

Google Analytics 4 (GA4) — Mesure d'audience anonymisée (nombre de visiteurs, pages vues, provenance). Les données sont envoyées à Google LLC (USA). La durée de conservation des données est de 14 mois. Google est certifié dans le cadre du Data Privacy Framework (DPF) EU-US, garantissant un niveau de protection adéquat.

Google Tag Manager (GTM) — Outil de gestion de balises qui permet de déployer et mettre à jour les scripts analytiques sans modifier le code source du site.

Google Ads (Conversion Tracking) — Mesure des conversions issues des campagnes publicitaires Google Ads (soumission de formulaire, appels téléphoniques). Ces données permettent d'optimiser nos campagnes sans identifier personnellement les utilisateurs.

En naviguant sur ce site, vous acceptez l'utilisation de ces cookies. Vous pouvez les refuser ou les gérer via les paramètres de votre navigateur, ou via l'extension de désactivation Google Analytics.
